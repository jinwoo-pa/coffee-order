# 커피 모아

스마트폰용 단체 커피 주문 웹앱입니다. 대표가 한 잔씩 입력하고 개인별 주문과 이름 없는 카페 집계를 확인합니다.

## 스마트폰에서 사용

[커피 모아 열기](https://jinwoo-pa.github.io/coffee-order/) — 아이폰 Safari 또는 안드로이드 Chrome에서 접속하세요. 최근 주문은 이 주소를 사용한 브라우저에 저장됩니다. PC 로컬 미리보기의 주문은 자동으로 옮겨지지 않습니다.

## 실행

Node.js가 설치된 환경에서 `npm start`를 실행하고 http://127.0.0.1:4173 에 접속합니다. 외부 패키지 설치는 필요 없습니다. `npm test`로 집계와 저장 테스트를 실행합니다.

## 사용

이름·커피·HOT/ICE·크기를 입력해 주문을 추가하고 주문 완료를 누릅니다. 개인별 목록은 커피 배부용, 카페 집계는 주문 전달용입니다. 주문 완료는 실제 카페에 주문을 전송하지 않습니다.

최근 주문 한 건만 같은 브라우저에 저장됩니다. 완료한 주문은 재접속하면 결과 화면으로 열립니다. 새 주문 시작과 주문내역 삭제는 확인 후 이전 내역을 지웁니다. 추가 메뉴는 유지됩니다. 앱 전체 초기화는 추가 메뉴까지 지웁니다. 브라우저 데이터 삭제, 비공개 모드 종료, 접속 주소 변경 시 기존 주문을 확인하지 못할 수 있습니다. 저장 실패 안내가 뜨면 창을 닫기 전에 주문을 확인하세요. 여러 탭에서 동시에 편집하지 마세요.

## HTTPS 배포

`index.html`, `styles.css`, `app.js`, `core.js`, `icon.svg`를 같은 디렉터리에 정적 호스팅하면 됩니다. 하위 경로 배포도 가능합니다. 개발용 `server.mjs`는 로컬 미리보기 전용입니다. HTTPS 주소를 아이폰 Safari나 안드로이드 Chrome에서 열어 사용하세요. 홈 화면에 추가할 수도 있습니다. 오프라인 사용은 제공하지 않습니다.

GitHub Pages의 `main` 브랜치 루트에서 공개합니다. 운영 Ubuntu 서버 설정과 서비스는 변경하지 않았습니다. 로컬 미리보기 주소는 해당 PC에서만 사용할 수 있습니다.
